# Contributing

Bug reports, setup feedback and pull requests are welcome. Chinese and English are both welcome.

Before proposing a large feature, open an issue describing the listening workflow you want to improve.

For code changes, run `swift test` and `./scripts/build-app.sh`. Keep the default narration faithful to the original reply. Do not introduce external AI services without making their data flow explicit.

Never include real private Claude replies, API keys or user settings in reports or test fixtures.
